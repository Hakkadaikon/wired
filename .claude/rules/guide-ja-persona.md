# guide 日本語ページの読者ペルソナ

`guide/` の日本語ページ(`.mdx`)を書く・推敲するときは、読者を**経験2年目くらいの一般的な
Web エンジニア**と想定する。

- TLS/QUIC/HTTP3/WebTransport/MoQT のプロトコル詳細は未経験という前提で書く。RFC の節番号や
  ドラフトの用語をいきなり出さず、先にその概念が何をするものかを一言説明してから使う。
- 「当然知っているはず」の暗黙の前提を置かない。知らなくても読み進められるように、専門用語は
  初出時に短く言い換えるか、具体例を添える。
- 日本語の文章としての自然さ・読みやすさは `yomiyasu` スキル(ユーザーグローバル)の規範に従う。
  このファイルはペルソナ(想定読者)だけを定め、文体の変換規則そのものは定義しない。
