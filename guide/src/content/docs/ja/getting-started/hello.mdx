wired のプログラムは libc（C の標準ライブラリ）を使いません。
`main` も `printf` もありません。
代わりになるものを `wired.h` が用意しており、このページではそれだけを使う最小のプログラムを示します。

<Example id="hello" />

## 仕組み

- `#include "wired.h"` の前に `#define WIRED_MAIN` を置くと、エントリポイント `_start` と、`-nostdlib` のバイナリが必要とする `memcpy`/`memset` が生成されます。
  定義するのは 1 ファイルだけにします。
- `_start` は `wired_main(argc, argv)` を呼び、その戻り値が終了ステータスになります。
- `wired_log_str` は NUL 終端の文字列を標準エラー出力に書きます。

## ビルドと実行

SDK のアーカイブを一度ビルドし、それに対して自分のファイルをフリースタンディング（標準ライブラリに依存しない形）でコンパイルします。

```sh
just lib
clang -target x86_64-linux-gnu -ffreestanding -fno-stack-protector \
      -fno-builtin -nostdlib -static \
      -Isrc -o hello main.c build/libwired.a
./hello
```

このガイドの他のページも、同じ手順でビルドできます。
