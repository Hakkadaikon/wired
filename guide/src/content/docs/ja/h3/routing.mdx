wired にルーターはありません。
ハンドラーがリクエストの `:path` を読み、応答を決めます。
このページのサーバーは `/` と `/about` に応答し、それ以外のパスには空のボディを返します。

<Example id="h3-routing" />

## 仕組み

- `req->path` と `req->path_len` がリクエストの `:path` を保持します。
  NUL 終端ではないので、1 バイトずつ比較します。
- ハンドラーが 0 を返すと、ボディのない 200 が送られます。
- ハンドラーはまだステータスコードを選べず、どの応答も 200 になります。
  そのため、この例では未知のパスを 404 ではなく空のボディで示しています。
- `wired_log_str` は NUL 終端の文字列を必要とするので、`log_request` はパスをいったんローカルのバッファーにコピーします。
