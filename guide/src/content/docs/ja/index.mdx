title: wired ガイド
description: wired の各機能を、動く最小のコードとその実際の出力で試す。
---

wired は C で書かれた libc 非依存の TLS 1.3 / QUIC / HTTP/3 / WebTransport / MoQT サーバー SDK です。
各ページには、コピーしてそのまま使える完全なプログラムと、その出力を載せています。
出力は、CI が独立したクライアント（[quic-go](https://github.com/quic-go/quic-go)、[webtransport-go](https://github.com/quic-go/webtransport-go)）を相手に最後に実行したとき、実際に表示されたものです。

ビルドコマンドは [はじめての wired](./getting-started/hello/) で説明しています。
まずここから読んでください。
サンプルが前提にしている設計上の考え方は、「考え方」のページで説明しています。
[MoQT へのメディアの載せ方](./concepts/media-mapping/)、[ストリームとデータグラム](./concepts/streams-vs-datagrams/)、[ブラウザーの要件](./concepts/browser-requirements/)、[SDK とアプリの役割分担](./concepts/responsibilities/)、[現在の上限](./concepts/limits/) があります。

各層は、表で一つ上にある層の上に成り立っています。
HTTP/3 のページは下で QUIC と TLS を動かしており、WebTransport は HTTP/3 の上で、MoQT は WebTransport の上で動きます。

個々の関数と構造体は [API リファレンス](https://hakkadaikon.github.io/wired/) を参照してください。
アプリケーション全体の例は [moqt_chat デモ](https://hakkadaikon.github.io/wired/moqt_chat/) にあります。
