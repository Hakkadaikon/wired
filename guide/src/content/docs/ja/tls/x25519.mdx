X25519 は、TLS 1.3 のハンドシェイクで行う鍵交換（両者が同じ秘密の値を共有するための計算）です。
このページでは、X25519 を定める RFC 7748 の 6.1 節にある Alice と Bob の秘密鍵を使うので、表示される値はすべて同じ節の値と一致します。

<Example id="tls-x25519" />

## 仕組み

- `wired_x25519_base(pub, priv)` は 32 バイトの秘密鍵から公開鍵を計算します。
- `wired_x25519(shared, priv, peer_pub)` は自分の秘密鍵と相手の公開鍵を組み合わせます。
  両者が同じ秘密を得ます。
- 相手の公開鍵が低位数（low-order）の特殊な点だと計算結果はすべてゼロになり、`wired_x25519` は 0 を返します。
  呼び出し側はこの戻り値を拒否しなければなりません（RFC 7748 6.1）。
