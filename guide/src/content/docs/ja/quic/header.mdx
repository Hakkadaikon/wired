ロングヘッダーは、QUIC が接続を確立するまでのパケットに使うヘッダー形式です。
どのロングヘッダーも、同じ不変のフィールド（タイプ、バージョン、2 つのコネクション ID）から始まります。
このページでは Initial（接続の最初に送るパケット種別）のヘッダーをエンコードし、それをデコードし直します。

## 仕組み

- `wired_header` はヘッダーのフィールドを保持します。
  `long_type` には `WIRED_LP_INITIAL`、`WIRED_LP_0RTT`、`WIRED_LP_HANDSHAKE`、`WIRED_LP_RETRY` のいずれかを入れます。
- `wired_header_build_long(buf, cap, &h)` は先頭バイト、バージョン、長さ付きの DCID と SCID（宛先と送信元のコネクション ID）を書き込み、書いたバイト数を返します。
  バッファーに収まらないときは 0 を返します。
- `wired_header_parse(buf, n, &h)` はそれらを読み戻し、消費したバイト数を返します。
  入力が途中で切れているか不正なときは 0 を返します。
- `wired_dprintf` は数値と文字列 (`%llu`, `%08x`, `%s`) を stderr に書き出します。
  バイト列（組み立てたヘッダーと 2 つのコネクション ID）は、wired 独自の変換 `%.*H` で 16 進にして、同じ 1 回の呼び出しで出します。
  `%.*H` には、バイト数とバイト列の先頭を順に渡します。
  詳しくは [printf の書式](../../concepts/formatting/) を見てください。
