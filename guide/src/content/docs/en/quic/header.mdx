Every QUIC long header starts with the same invariant fields: type, version
and two connection IDs. This page encodes an Initial header and decodes it
again.

<Example id="quic-header" />

## How it works

- `wired_header` holds the fields; `long_type` takes `WIRED_LP_INITIAL`,
  `WIRED_LP_0RTT`, `WIRED_LP_HANDSHAKE` or `WIRED_LP_RETRY`.
- `wired_header_build_long(buf, cap, &h)` writes byte 0, the version and the
  length-prefixed DCID and SCID, and returns the byte count (0 if it does not
  fit).
- `wired_header_parse(buf, n, &h)` reads them back and returns the bytes
  consumed (0 on truncated or malformed input).
- `wired_dprintf` formats decimals (`%llu`) and hex bytes (`%02x`) to stderr.
