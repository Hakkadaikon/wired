SHA-256 is the hash under TLS 1.3's key schedule. This page hashes `abc`;
the digest is the "abc" test vector from FIPS 180 and RFC 6234.

<Example id="tls-sha256" />

## How it works

- `wired_sha256(data, len, out)` hashes `len` bytes into a
  `SHA256_DIGEST` (32) byte buffer in one call.
- `wired_dprintf(2, "... %.*H\n", (int)sizeof digest, digest)` writes the
  32-byte digest as hex in one call. `%H` is a wired-only conversion that
  prints bytes as hex; its precision (passed through `.*`) is the byte
  count. See [printf formats](../../concepts/formatting/).
