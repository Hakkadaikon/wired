An HTTP/3 server is a request handler plus a server identity. This page
answers every request with `hello`.

<Example id="h3-hello" />

## How it works

- `wired_server_run(port, &id, h, obs)` runs QUIC, TLS 1.3 and HTTP/3 on a
  UDP port and calls your handler once per request.
- `wired_srvboot_id` is the server identity: X25519 key pair, certificate
  signing seed, connection id and ServerHello.random. The demo derives it
  from fixed bytes; `wired_x25519_base` computes the public key.
- The handler writes the body into `body_out`, sets `*content_type`, and
  returns 1. Returning 0 sends a body-less 200.
- `wired_cliargs_int` reads `--port` from the command line.
