# RFC 9287: QUIC ビットのグリース(Greasing)

仕様の本文(`tasks/specs/rfc9287.txt`。git には含まない)から抽出した EARS 形式の要件台帳です。各要件には、それを確かめるテストを付けています。チェックがなくテスト行もない項目は、未解決のギャップです。2026-10 時点の状況です。

凡例:

- `[x]`: 挙げたテストで確認済み
- `[~]`: 間接的に確認(専用のテストはなく、evidence 行で確かめ方を説明)
- `[ ]`: まだどのテストでも確認していない

**カバレッジ: テスト済み 7/8、間接 1、未テスト 0。**

## §3 グリース QUIC ビットのトランスポートパラメーター

- [x] 9287-001 (§3) グリースを有効にした構成では、サーバーは grease_quic_bit トランスポートパラメーター(0x2ab2)を空の値で送らなければならない。
  - test: `tests/tls/server_tp_test.c` — `test_server_tp_grease_quic_bit`
    (`stp_build_server_ret`, the server flight's TP builder, emits it via
    `grease_encode`)
- [x] 9287-002 (§3) grease_quic_bit トランスポートパラメーターを理解する構成では、空でない値の grease_quic_bit を受け取った場合、サーバーはそれを TRANSPORT_PARAMETER_ERROR 型の接続エラーとして扱わなければならない。
  - test: `tests/tls/sdrv_test.c` —
    `test_sdrv_recv_client_hello_grease_quic_bit`
- [x] 9287-003 (§3) grease_quic_bit トランスポートパラメーターを広告している間、サーバーは QUIC ビット(0x40)が 0 のパケットを受け入れなければならない。
  - test: `tests/app/srvloop_test.c` —
    `test_srvloop_accepts_cleared_quic_bit` (no receive path tests the bit)

## §3.1 QUIC ビットのクリア

- [x] 9287-004 (§3.1) サーバーはピアが grease_quic_bit トランスポートパラメーターを広告した場合にだけ、QUIC ビットを 0 にしなければならない。
  - test: `tests/app/srvloop_test.c` — `test_srvloop_send_greases_quic_bit`
    (64 packets without the client's parameter all keep the bit;
    `greasebit_may_clear` gates `send_onertt_clear_bit`). Long-header
    builders always set 0x40.
- [x] 9287-005 (§3.1) ピアが grease_quic_bit を広告したとき、サーバーは QUIC ビットを予測できない値にするべきである。
  - test: `tests/app/srvloop_test.c` — `test_srvloop_send_greases_quic_bit`
    (both values occur; the bit is drawn from a per-connection random seed
    mixed with the packet number)
- [x] 9287-006 (§3.1) サーバーはクライアントのトランスポートパラメーターを処理し、自身も grease_quic_bit を広告したあとでなければ、QUIC ビットを 0 にしてはならない。
  - test: `tests/tls/sdrv_test.c` —
    `test_sdrv_recv_client_hello_grease_quic_bit` (the permission is only
    ever set from the ClientHello's TPs) with
    `test_srvloop_send_greases_quic_bit`; only 1-RTT packets, sent after
    the flight that advertises it, are greased.
- [~] 9287-007 (§3.1) サーバーは以前の接続で記憶したネゴシエーションの結果を根拠に、QUIC ビットを 0 にしてはならない。
  - evidence: 構造上の根拠。`peer_grease_quic_bit` は接続ごとの `sdrv` にあり、`sdrv_init` でリセットされる。チケットはグリースの状態を持たない。テストはない。
- [x] 9287-009 (§3.1) サーバーはピアがこの拡張をサポートしていると知らないまま、Stateless Reset を含むどのパケットでも QUIC ビットを 0 にしてはならない。
  - test: `tests/transport/sreset_test.c` — `test_sreset_build_fixed_bits`
    (`sreset_build` forces the first bits to 0b01 over any RNG output)

## 対象外

このサーバー SDK が実装しない主体や機能への要件です。カバレッジの分母には含めません。

- (§3.1) クライアントがサーバーのトランスポートパラメーターを受け取る前に QUIC ビットをクリアすることと、その前提条件(NEW_TOKEN / 7 日)。クライアントの振る舞い。
- (§3.2) QUIC ビットに意味を割り当てる拡張と、そのネゴシエーションの規則。そうした拡張は実装していない。
- (§4) グリースがネットワーク運用者のトラフィック分類に与える影響。運用者が考慮する事柄で、SDK のコードはない。
