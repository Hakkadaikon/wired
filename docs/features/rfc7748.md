# RFC 7748: セキュリティのための楕円曲線

仕様の本文(`tasks/specs/rfc7748.txt`。git には含まない)から抽出した EARS 形式の要件台帳です。各要件には、それを確かめるテストを付けています。チェックがなくテスト行もない項目は、未解決のギャップです。

凡例:

- `[x]`: 挙げたテストで確認済み
- `[~]`: 間接的に確認(専用のテストはなく、evidence 行で確かめ方を説明)
- `[ ]`: まだどのテストでも確認していない

**カバレッジ: テスト済み 13/16、間接 3、未テスト 0。**

## 対象外

このサーバー SDK が実装しない、クライアント専用または運用者向けの要件です。カバレッジの分母から除きます。

- (§4.2, §5, §5.2, §6.2) Curve448 / X448。実装していない。この SDK が実装するのは X25519 だけ。
- (§4.1) edwards25519 への双有理写像。参考情報。Ed25519 は [RFC 8032 の台帳](rfc8032.md) で扱う。
- (§5.1) サイドチャネルの研究を追うこと。参考としての助言。定数時間の要件そのものは 7748-008 と 7748-016。
- (§7) プロトコル設計者への指針(contributory な振る舞いの前提、等価な公開鍵、twist を拒否する実装)。設計の指針であり、実装としての振る舞いを持たない。
- (Appendix A) 曲線の導出手順。参考情報。
