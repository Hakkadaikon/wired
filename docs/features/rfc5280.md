# RFC 5280: インターネット X.509 公開鍵基盤 (PKI) 証明書および証明書失効リスト (CRL) プロファイル

仕様の本文(`tasks/specs/rfc5280.txt`。git には含まない)から抽出した EARS 形式の要件台帳です。各要件には、それを確かめるテストを付けています。チェックがなくテスト行もない項目は、未解決のギャップです。
範囲は、この TLS サーバー SDK が使う部分、つまり証明書の DER のパースと認証パスの検証です。

凡例:

- `[x]`: 挙げたテストで確認済み
- `[~]`: 間接的に確認(専用のテストはなく、evidence 行で確かめ方を説明)
- `[ ]`: まだどのテストでも確認していない

**カバレッジ: テスト済み 45/57、間接 12、未テスト 0。**

## 対象外

このサーバー SDK が実装しない、クライアント専用、CA や運用者のレベルの要件、または意図して提供していない要件で、カバレッジの分母から外しています。
